PARVEZ Business Manager — Android Studio Project

এই ফোল্ডারটি Android Studio-তে Open করে APK তৈরি করার জন্য প্রস্তুত করা হয়েছে।

গুরুত্বপূর্ণ:
- এটি এখনো ইনস্টল করার মতো APK ফাইল নয়; এই পরিবেশে Android SDK/Gradle build tools নেই, তাই APK compile করা যায়নি।
- Android Studio (Jellyfish বা পরের সংস্করণ) ও Android SDK 35 ইনস্টল করা কম্পিউটারে project খুলুন।
- Gradle sync শেষ হলে Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।
- APK পাওয়া যাবে: app/build/outputs/apk/debug/app-debug.apk
- APK ফোনে পাঠিয়ে Install করুন। প্রয়োজনে Android সেটিংসে এই উৎস থেকে ইনস্টল অনুমতি দিন।

অ্যাপের বৈশিষ্ট্য:
- দোকানভিত্তিক শাড়ি সরবরাহ, পেমেন্ট, পাওনা
- আব্বাস বেনারসী ও কুমকুম স্টন হাউসের কেনাকাটা
- অন্যান্য খরচ, সারসংক্ষেপ ও আনুমানিক লাভ
- ফোনের অ্যাপ ডেটায় হিসাব সংরক্ষণ
- রিপোর্ট থেকে JSON ব্যাকআপ সেভ এবং ব্যাকআপ ফাইল Restore
- PARVEZ মেরুন-গোল্ড লোগো ও অ্যাপ আইকন

সতর্কতা: নিয়মিত রিপোর্ট > ডেটা ব্যাকআপ থেকে ব্যাকআপ নিন। অ্যাপ আনইনস্টল বা ফোন নষ্ট হলে লোকাল ডেটা হারাতে পারে; ব্যাকআপ ফাইল আলাদা জায়গায় রাখুন।
